## What I need from you (drawings made in ChatGPT)

### Rules for EVERY drawing
1. **One drawing per file**, PNG, **transparent background**, no text, labels or arrows. ChatGPT's 1536×1024 size is fine (I fit it to 16:9).
2. **Character (and the prop in their hand) only.** No room or background, unless the item is listed as a BACKGROUND.
3. **Make each new key by editing the previous key of the same shot.** Upload the previous PNG and say "same character, same size, same position, change only …". Don't start from a blank image; that's what made V5-V7 drift.
4. Always attach the master sheet `SCIENTIST_PREMASK_20_POSES.png` (or the Mr X sheet for masked shots) as reference.
5. Same size and position within a shot. Full body unless the shot says close-up.
6. File name = the code in the tables below (e.g. `SH06_K01.png`).

### Priority order
1. **Designs first** (needed by several shots): D1 ghost, D2 city background.
2. Shots in story order: SH06 → SH15, then the intro SH01-SH05.
S01 (SH08) already has its 6 keys; its breakdowns from BREAKDOWN_BRIEF.md are optional (better motion).
